# WebBlock

## About
WebBlock is a Blockchain that is web based and allows people to make their own coins, Sell them and Exchange them. The Default currency is WBD (WebBlock Dollar) what can be used to buy coins


## Features
- 🪙 Create coins
- 🟢 Buy coins
- 🔴 Sell coins
- 💱 Exchange Coins
- 📊 View a Treemap graph of the entire blockchain
- 🏆 Compete on leaderboards
